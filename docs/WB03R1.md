# WB03R1：3.5 寸独立 RGB888 诊断与完整初始化延时

2026-09-30，Efinity 2025.1.110 新构建完成。本版本为**电脑端验证通过、实机待验证的候选**，尚未下载到板子。实际 PCB 版本、电平、颜色顺序和屏幕效果仍待确认；板上继续保留原厂对照配置。

## 实现与验证路径

`projects/mipi_diag` 是独立工程，保留 WB02 原厂载体的时钟、CSI / DDR / I2C、DSI 硬块及 3.5 寸初始化表。新增 `mipi_diagnostic_rgb2` 用本地计数器产生完整 DE/HS/VS 和每拍两个 RGB888 像素，直接送入 DSI；像素和同步不使用相机、DDR、debayer 或白平衡输出。载体 PLL 锁定复位与 DSI 启动过程仍有依赖，不能称为无时钟 / 初始化依赖的设计。

两个通道分别由自己的 `pixel_data_en` 启动。默认显示八色竖条，底部为逐像素橙 / 蓝交替图案，外围一像素白边；无需寻找模式按键。颜色与两个像素在 RTL 总线中的顺序为：

```text
bits [63:48] = 0
bits [47:24] = pixel(x+1): R[23:16], G[15:8], B[7:0]
bits [23:0]  = pixel(x):   R[23:16], G[15:8], B[7:0]
```

RTL 总线顺序已检查，实际 DSI 字节传输、面板 RGB / BGR 设置、旋转和裁剪尚未现场验证。原厂前后肩不变：1,066 个双像素时钟 / 行、1,122 行 / 帧，共 1,196,052 个时钟 / 帧；依据 SDC 14.286 ns 视频周期推算约 **58.5247 Hz**，不是板上测量或赛题 HDMI 60 Hz 验收。

## 初始化修正

### 首次 AXI 状态读取

原版在 ARVALID/ARREADY 握手时仍提供地址 0，直到握手边沿才更新到 `0x24`。原版仿真复现错误。诊断候选把地址放到 ARVALID 之前，并在轮询重试时明确保持 `0x24`，通过带随机等待的参考 AXI 从设备检查。

### 延时字段高位

原 `r_timer[21:0]` 只与 `w_reg[21:0]` 比较，截断了 32 位 ROM 延时。原厂表中 `0x04C4B400` 为 **80,000,000 周期**，截断后仅剩 **308,224 周期**。依据 100 MHz core_clk 约束，它们分别是 0.8 s 和 3.08224 ms；这只是约束下的换算，未测量实机等待。

WB03R1 改为完整 32 位计数 / 比较 / 清零，保留原厂 ROM 每一字节。表中 50 个延时项合计 82,088,320 周期，旧截断合计 2,396,544 周期；这些数值不含每行控制开销、AXI 等待、PLL 锁定或随后视频启动延时。

独立边界测试只让两张表的延时相差 bit22，其他写入及响应完全一致：

| 控制器 | 短延时第二次 AW | 长延时第二次 AW | 时间差 / 周期 | 结论 |
| --- | --- | --- | --- | --- |
| WB03，22 位 | 28 | 28 | 0 | 失败，候选拒绝 |
| WB03R1，32 位 | 28 | 4,194,332 | 4,194,304 | 通过，延时高位保留 |

测试观察外部 AXI 握手与载荷，没有强制改写计数器或跳过中间周期。它验证延时 bit22 的边界和计数器字段；加密 DSI IP、物理 D-PHY、面板所需等待时间和实际启动仍待现场验证。

## 验证结果

- 新版常规回归：254,437 项时钟 / 像素 / 协议检查通过，另增加延时边界测试；原有滤波、完整连接、缓存、三拍输出与白平衡回归均通过。
- AXI 初始化：三次完整配置，每次 119 写 / 357 状态读，含两次忙状态再转空闲、1,472 个等待周期，以及读取中途异步复位。快速模型保留真实写载荷，仅把 50 个延时项缩成 3 周期，并为 ROM 未指定行显式补 0；不能据此验收物理等待时间。
- 延时边界：逐周期跑到第二次长延时 AW，时间差为 4,194,304 周期，通过。
- 全尺寸 RGB / 同步模型：3,614,865 个时钟与 6,220,806 个像素检查通过；结果来自 WB03。WB03R1 已用 Git 原始字节 / SHA256 确认发生器、顶层接线、DSI wrapper、初始化表、GPIO XML 和 SDC 均未改变，保留了明确的验证来源；本轮重新测试了变化的初始化控制器。
- 供应商 DSI 约束适用检查通过，没有增加新的时序例外。
- Efinity map / interface / pnr / pgm 四阶段通过，生成本轮新的 bit / hex。

Icarus 保留供应商 RAM 模板关于数组方向 / readmemh 标准的提示；该仿真按 Verilog 2005 / SystemVerilog 行为读表，没有屏蔽警告。构建的原始 warning / CDC 报告也随发布保存。
