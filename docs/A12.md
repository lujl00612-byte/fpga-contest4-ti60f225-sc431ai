# A12：完整连接的双字缓存

## 实现与验证范围

A11 缓存最近访问的一个打包字。A12 继续使用现有写回寄存器保存最近使用的字，增加一个 20 位字、字地址和有效位，保存被移出的字。两个字均可命中；命中第二个字时交换两者，新字未命中时淘汰最久未访问的字。

640×480 配置新增逻辑存储为 20+16+1=37 位，不增加 BRAM 或 DFS 栈。命中仍为三周期，未命中四周期，RAM 写回仍在请求者消费 ready 的 ACK 时钟沿提交。写入命中第二个字时，先交换数据，再更新目标标签；其他四个标签保持原值。

捕获、视频读回及其延迟拍、复位使两个缓存字都失效。ACK 前中止写入时丢弃未提交数据。视频 RAM 两拍读取和最终 RGB / DE / HS / VS / 独立边缘标记三拍流水线保持一致。生产接口仍要求捕获、连接处理和显示互斥。

## 处理周期与 RAM 读取

使用相同增强测试校准 Git 标签 A11 的存储源码。独立软件 MRU 列表预测握手延迟；数据使用单元参考和 BFS，检查请求等待 / ACK 时的稳定性，以及实际 RAM 读次数等于缓存未命中数。

供应商 RAM 模型与简化字模型在四个 40×80 场景的结果、周期、访问、写入、命中和 RAM 读取记录完全相同。全尺寸使用经过该对照的简化原语模型与生产引擎 / 控制器，覆盖所有 120 块 RAM：

| 640×480 场景 | A11 周期 | A12 周期 | 新增减少 | A11 RAM 读 | A12 RAM 读 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全弱、无强种子 | 1,290,240 | 1,290,240 | 0 | 61,440 | 61,440 |
| 一个强种子、全网格弱像素连通 | 14,842,638 | 14,165,428 | 677,210，4.56% | 1,653,186 | 975,976 |

全连通 RAM 读相对 A11 再减少约 40.96%。算法访问仍为 3,372,484 次，写入仍为 307,200 次，保留像素 307,200 个；缓存命中从 1,719,298 增至 2,396,508。A11 与 A12 的周期差恰好等于新增命中数。无种子顺序扫描只需单字缓存，因此第二个字没有额外收益。

按 148.5 MHz 折算，全连通处理段从约 99.95 ms 降至约 95.39 ms，无种子仍约 8.69 ms。这是仿真周期换算，尚未板上计时，且不包括冻结等待、捕获和帧边界发布。收益依赖访问局部性，不能用两场景保证任意画面的百分比收益。

时间复杂度仍为 O(P)，状态仍为 4P 位加固定大小缓存 / 控制寄存器。请求数上界 `P+10V` 不变，周期上界仍为 `5P+49V+2-H`，其中 P 为 ROI 像素数、V 为保留像素数、H 为缓存命中请求数。

## MIPI 诊断准备与待验收
