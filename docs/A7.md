# A7：基础模式、帧冻结与识别显示

## 改动

- 默认进入基础 Sobel：左半边显示原始 RGB 按 77/150/29 转换的灰度，右半边显示二值边缘。
- 基础模式保留灰度原像素，绕过中值和 Gaussian 运算的输出，使用 `|Gx|+|Gy|`，按键阈值直接参与比较。
- 中值 / Gaussian / NMS 共享已有行存储与时序通路。进阶模式使用中值、Gaussian、L1 梯度、方向、NMS 和双阈值，右边红色边缘叠加原图。
- 冻结请求经过两级同步，整帧开始前门控 VS 与写像素；不在有效像素中途改变。继续显示 DDR 已完成的帧。
- 使用当前帧轮廓顶部跨度识别平顶矩形和近似圆形，替代依赖上一帧框位置的角点计数。单个主要图形的结果显示为 `CIRCLE`、`RECTANGLE`、`UNKNOWN`；基础模式标题为 `SOBEL`。
- 基础显示不再使用经过中值 / Gaussian 的灰度作原图对照。移除被综合优化掉的重复灰度缓冲后，RAM10 从 A6 的 134 块降至 130 块。

## 按键

- KEY0：降低阈值。
- KEY3：提高阈值。
- 两键同时短按后松开：冻结 / 恢复。
- 两键同时按住约 1 秒：切换基础 / 进阶算法，松开时不触发冻结。

## 保留的限制

进阶连续视频的滞后连接仍是一层局部近似；A8 正在实现完整任意长度连接。识别为简单单目标启发式，多目标或复杂背景不保证分类正确。HDMI 尚未连接，不能把构建和仿真替代实机画面、DDR 冻结 / 回放和演示录像验收。
