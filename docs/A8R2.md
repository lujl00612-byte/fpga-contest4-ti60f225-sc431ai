# A8R2：完整 Canny 滞后连接接入冻结画面

## 功能与范围

保留 A7 的全部基础模式、按键、DDR 冻结 / 回放、红色叠加和形状文字。

在进阶模式冻结后，等待三个显示帧让摄像头写入停止，捕获右侧 `x=960..1599，y=0..479` 的 640×480 NMS 双阈值分类，执行完整 8 邻域滞后连接，在之后的帧边界发布结果。每条与强边缘连通的弱边缘链都保留，任意长度链和闭环不会只保留一层。

分析区域下方有状态条：黄色为等待 / 计算，绿色为结果就绪。改变阈值会重新捕获和分析。解冻后回到连续视频的局部近似通路。

**完整连接的验证范围是冻结的 640×480 分析区域；全帧实时 Canny 尚未完成。** HDMI 显示时序仍为 1080p60，分析耗时和显示刷新率是两项不同的指标。

形状检测新增独立边缘标记通路，避免把原场景的红色物体直接当作算法边缘。纯红场景、没有边缘标记时的回归通过。

## 时间与存储复杂度

令 P 为分析区域像素数，V 为最终保留的像素数。

- 每个像素只作一次强种子扫描。
- 每个保留像素的 8 个邻居各检查一次；返回子节点时，从像素状态中恢复父节点方向及下一邻居编号。
- 存储访问次数 ≤ P+10V，时间 **O(P)**。
- 每个像素用 4 位：背景、弱、强、访问根或八种返回方向。无额外 DFS 栈，状态存储为 **4P 位**。
- 五个状态打包为 20 位，显式使用 512×20 `EFX_RAM10`。640×480 状态占 120 块 RAM10。

A8 的两读两写描述无法映射到目标 RAM；A8R1 的自动推断把 20 位拆为 16+4，导致总物理 RAM 达 284/256。A8R2 复用读写端口并使用完整 20 位模式，总占用 **254/256**，降低了 30 块 RAM。两次失败源码、日志及原因也有 Git 标签保存。

## 仿真与构建证据

| 检查 | 结果 |
| --- | --- |
| A7 及白平衡回归 | 92,222 项检查 PASS |
| 24 帧完整连接与独立 BFS | 18,432 像素 PASS；含长链、闭环、对角线和存储等待 |
| 冻结快照、打包 RAM、发布 / 重新捕获 | 52,059 项时序、13,440 项输出颜色检查 PASS |
| 跨 RAM 块边界，使用厂商 RAM 模型 | 162,954 项时序、40,320 项输出颜色检查 PASS |
| 完整 640×480，无强种子 | 307,200 像素均丢弃；921,600 周期，307,200 次存储访问 |
| 完整 640×480，单强种子和全连通弱像素 | 307,200 像素均保留；9,816,968 周期，3,372,484 次存储访问 |
| Efinity 2025.1.110 | map / interface / pnr / pgm 实际执行 PASS；生成 `.bit`、`.hex` |
| LUT4 / FF / DSP24 | 14,849 / 9,778 / 12 |
| RAM10 / DPRAM10 | 250 / 4 |
| 像素时钟 | 148.5 MHz，setup **+0.435 ns**，hold **+0.028 ns** |
| 报告最高像素频率 | 158.755 MHz |
| 已分析 setup 路径 | 均为正裕量 |

全尺寸核心测试的存储模型为两周期响应；发布版 RAM 控制为四周期响应。不能将 9,816,968 周期直接称为发布版硬件耗时。对发布版控制，在每次访问四周期的条件下，完整计算上界为 `5P+49V+2` 周期，最密情况下约 1,659 万周期；按 148.5 MHz 算约 112 ms，另有冻结等待、捕获和帧边界发布时间。这是上界估算，尚未板上计时。
