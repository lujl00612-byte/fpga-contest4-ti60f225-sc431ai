# A9：完整连接 RAM 写回分级

## 本轮改动

A8R2 的像素域最长路径从 RAM 读端，经 120 块选择、单标签读改写和捕获数据选择，直接到另一 RAM 块的写数据端。该路径有 9 级逻辑，148.5 MHz 的 setup 裕量为 +0.435 ns。

A9 在 `canny_tag_memory.v` 增加 20 位写回寄存器，利用原有 ACK 状态提交写入。请求方在同一时钟沿消费 `req_ready`，因此写入完成时间满足原接口约定，响应周期数保持为四。视频读取通路及其像素同步流水线不变。

| 请求的时钟沿 | A8R2 | A9 |
| --- | --- | --- |
| 1：IDLE | 锁存地址 / 请求 | 锁存地址 / 请求 |
| 2：READ_WORD | RAM 读取 | RAM 读取 |
| 3：RESPOND | 组合读改写直接写 RAM，产生 ready | 将更新后的完整字寄存，产生 ready |
| 4：ACK | 请求方消费 ready | 寄存字写 RAM，请求方消费 ready |

捕获写入仍直接使用捕获字。保持五个 4 位标签组成一个 20 位字、120 个 512×20 标签 RAM、完整八邻域 DFS、阈值重新捕获和帧边界发布。

## 周期数与复杂度

令 P 为 ROI 像素数，V 为最终保留像素数。

- 状态空间仍为 **4P 位**，没有额外 DFS 栈；新增的写回寄存器是固定 20 位。
- 每个像素扫描一次，每个保留像素的八个邻居各检查一次，访问次数 ≤ `P+10V`，时间仍为 **O(P)**。
- 每次访问四周期，扫描和推进 ≤ `5P`，访问像素的 CHOOSE / 邻居读取 / 标记写入 / 返回读取 ≤ `49V`；计算上界仍为 `5P+49V+2`。

这轮优化物理读改写路径，访问次数、处理周期和渐近复杂度保持不变。

## 仿真验证

使用本机 MSYS2 Icarus 12.0。

| 检查 | 范围 / 结果 |
| --- | --- |
| 原回归 | 176,153 项检查 PASS：白平衡、滤波、控制、形状、完整连接和快照 |
| 快照跨 RAM 块 | 162,954 项时序、40,320 项输出检查 PASS；采用供应商 RAM 模型 |
| 新增 RAM 接口测试 | 40×80、四场景，12,800 个打包单元与独立 BFS 比较 PASS；请求等待 / 确认时保持稳定，全部四周期响应，未保留单元无意外修改 |
| RAM 模型对照 | 供应商位级模型与简化字级模型在上述四场景的输出检查、周期、访问和写入次数一致 |

新增测试已加入 `tools/test.ps1`。全尺寸测试使用生产 `canny_hysteresis_exact.v` 和 `canny_tag_memory.v`，RAM 原语采用经过上述对照的简化 512×20 按字模型，以降低仿真开销。它仅支持本工程使用的完整字写入、无 RAM reset、无同时读写配置；未用该简化模型验证其它原语模式。

| 640×480 场景 | 保留像素 | 周期 | 存储访问 | 写入 |
| --- | ---: | ---: | ---: | ---: |
| 全弱、无强种子 | 0 | 1,536,000 | 307,200 | 0 |
| 一个强种子、全网格弱像素连通 | 307,200 | 16,561,936 | 3,372,484 | 307,200 |

计数来自完整四周期控制器的 RTL 仿真，两版一致。按 148.5 MHz 折算分别为约 **10.34 ms / 111.53 ms**，另有冻结等待、捕获和帧边界发布。这是频率折算，尚未板上计时。A8R2 原文档的 9,816,968 周期来自二周期存储模型；本轮改用完整控制器获得可对应发布 RTL 的计数。

## 实际构建与时序

使用 Efinity 2025.1.110 / Ti60F225I3，map、interface、pnr、pgm 四阶段均 PASS，新 bit / hex 已生成。

| 指标 | A8R2 | A9 | 变化 |
| --- | ---: | ---: | ---: |
| LUT4 | 14,849 | 14,531 | −318 |
| FF | 9,778 | 9,717 | −61 |
| RAM10 / DPRAM10 | 250 / 4 | 250 / 4 | 仍为 254 / 256 |
| DSP24 / DSP48 | 12 / 4 | 12 / 4 | 不变；旧清单的 DSP48 从 info.log 核对 |
| 148.5 MHz 像素域 setup 裕量 | +0.435 ns | +0.556 ns | +0.121 ns |
| 像素域 hold 裕量 | +0.028 ns | +0.026 ns | −0.002 ns，仍通过 |
| 像素域分析最高频率 | 158.755 MHz | 161.865 MHz | +3.110 MHz |

A9 的 18 组 setup 与 18 组 hold 均为正裕量；全设计最小 setup / hold 分别为 +0.296 ns / +0.026 ns。像素域最长路径已转为标签 RAM 读输出 → 结果着色流水线 `u_exact/rgb1[23]`，12 级逻辑、数据延迟 4.688 ns；读改写组合路径已经分级。资源变化取自实际布局布线报告，不据此推断所有寄存器减少的具体原因。

- bit SHA256：`BC1FF11B3E6824E1C874B5F2CD327C9288C854DCCAFF6311309B76D0E4E7F979`
- hex SHA256：`1C3DAC9D15807F20520CC517868001A1E930EC2B511ABEE3A46BEC0C6336B807`

报告、测试日志、模型对照、基线源码和复现命令随发布保存；清单包含证据文件 SHA256。两种下载文件均与本轮 build 文件逐字节一致，与 A8R2 的下载文件不同。

### PowerShell 复现命令补充

归档的 `verification-commands.ps1` 中带 `-Ptb_*.参数=值` 的参数应作为完整字符串传给 Icarus。PowerShell 可能在未加引号时把点号两边拆为多个参数，导致 `.RW=40: No such file or directory`；这属于命令解析错误。复现跨 RAM 块测试时使用 `'-Ptb_snapshot.RW=40' '-Ptb_snapshot.RH=80'`，全尺寸时使用 `'-Ptb_hysteresis_ram.W=640' '-Ptb_hysteresis_ram.H=480' '-Ptb_hysteresis_ram.SCENES=2'`。原 A9 测试的编译输出与 PASS 日志已保存；后续发布命令均对这些参数加引号，不改变已归档的报告或下载文件。
