# A11：完整连接的单字缓存

## 改动与一致性

A10 对每个标签请求都读取 RAM，每个打包字包含五个 4 位标签。A11 复用已有 `write_word_q` 保存最近访问的整个 20 位字，复用 `word_addr` 作为字身份，仅增加固定大小的缓存控制。命中跳过 RAM 读取状态，请求从四周期变为三周期；未命中仍为四周期。

写入仍在请求者消费 `req_ready` 的 ACK 时钟沿提交。写响应返回该单元的旧标签，再把修改后的完整字提交到 RAM；读请求保存原字，避免破坏相邻标签。重新捕获、视频读回及其延迟拍、复位都使缓存失效。ACK 前复位会丢弃尚未提交的缓存写入，RAM 保持原内容。

视频 RAM 读取仍为两拍，快照 RGB、DE、HS、VS 和独立边缘标记仍为三拍。生产接口继续要求捕获、连接处理和结果显示互斥；本版没有增加并发仲裁。

## 周期与 RAM 访问实测仿真

使用生产完整连接引擎及生产 RAM 控制器。A10 从 Git 标签提取源码，用相同测试校准；四个 40×80 场景中，结果、算法访问数及写入数一致，减少的周期数恰好等于缓存命中数。供应商 RAM 模型与简化字模型的四个场景记录完全一致。

640×480 使用上述经过对照的简化 RAM 原语模型，检查全部 120 块标签 RAM、614,400 个单元，并与 A10 已保存的全尺寸记录对照：

| 场景 | A10 周期 | A11 周期 | 减少 | A10 RAM 读 | A11 RAM 读 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全弱、无强种子 | 1,536,000 | 1,290,240 | 245,760，16.00% | 307,200 | 61,440 |
| 一个强种子、全网格弱像素连通 | 16,561,936 | 14,842,638 | 1,719,298，10.38% | 3,372,484 | 1,653,186 |

全连通保留 307,200 个像素，算法访问仍为 3,372,484 次，写入仍为 307,200 次；缓存命中 1,719,298 次，RAM 读减少约 50.98%。无种子场景算法访问仍为 307,200 次、写入为零，RAM 读减少 80%。这是对 RAM 读取与等待周期的优化，DFS 访问次数没有减少。

按实际约束的 148.5 MHz 折算，处理段为约 8.69 / 99.95 ms，A10 为约 10.34 / 111.53 ms。尚未板上计时，且这些数值不含冻结等待、捕获和帧边界发布。

令 P 为分析区域像素数、V 为保留像素数、H 为缓存命中请求数：

- 时间复杂度仍为 **O(P)**，状态为 **4P 位加固定寄存器**，没有新增 RAM 或 DFS 栈。
- 算法请求次数仍满足 `P+10V` 上界。
- 在本控制器的三 / 四周期握手下，处理周期满足 `5P+49V+2-H` 上界。
- 缓存收益随空间局部性变化，不用两个测试场景的百分比保证任意画面收益。

## 验证记录

- 常规回归通过 236,375 项检查，包括白平衡、滤波、控制、形状、独立 BFS、快照以及生产 RAM；新增缓存专项通过 321 项数据 / 延迟 / 一致性检查。
- 缓存专项覆盖读写相邻标签、跨块访问、捕获覆盖、视频读回、复位，以及命中与未命中两种写入在 ACK 前中止；随机读写后按单元参考模型检查完整字。
- 生产 RAM 握手检查请求在等待与 ACK 时稳定，并核对实际 RAM 读次数等于缓存未命中数。
- 跨块快照通过 155,547 项同步、40,320 项颜色、155,547 项独立边缘标记检查；使用供应商 RAM 模型。变量 RGB 与纯红背景能检查错位及边缘标记误判，重新捕获和帧边界发布通过。
- 全尺寸两场景独立 BFS / 读回通过；A10 周期等于 A11 周期加命中数。

快照处理提前完成，测试结束帧也提前，因此同步检查总数少于 A10；仍覆盖相同的两个场景、重新捕获与发布条件。
