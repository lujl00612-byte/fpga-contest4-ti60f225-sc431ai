# A10：完整连接结果显示分级

## 改动与接口约定

A9 像素域最长路径从标签 RAM 的读输出，经 120 块选择、单标签选取与颜色判断，到 `u_exact/rgb1[23]`。该路径有 12 级逻辑，148.5 MHz 的 setup 裕量为 +0.556 ns。

A10 为视频读取增加一个 20 位选中字寄存器，将单标签判断及红色叠加移到已有的最终输出级。引擎继续直接使用原 RAM 读字，四周期请求接口保持不变。基础滤波、阈值、冻结、完整连接算法和白平衡源码均未修改。

| 输入后的时钟沿 | A9 | A10 |
| --- | --- | --- |
| 1 | RAM 读取、坐标 / RGB / 控制信息锁存 | 相同 |
| 2 | RAM 选择、标签判断、灰度或颜色叠加 | RAM 选中字寄存；计算灰度 / 状态色；锁存标签位置及叠加条件 |
| 3 | 结果输出，边缘标记输出 | 寄存字的标签判断、叠加与结果输出 |

最终 RGB、DE、HS、VS 和独立边缘标记仍为三拍流水线。存储视频端口现在是两拍读出；完整连接引擎仍为四周期，不增加其处理周期。新逻辑只有固定数量的寄存器，没有增加标签 RAM 或 DFS 栈。

## 仿真依据

使用本机 MSYS2 Icarus 12.0。

- 常规回归通过 241,012 项检查，包括新增的 52,059 项独立边缘标记检查，以及实际 RAM 接口的 12,800 个打包单元检查。
- 跨 RAM 块快照：162,954 项同步检查、40,320 项颜色检查、162,954 项独立边缘标记检查。使用供应商 RAM 原语模型；像素颜色随坐标变化，并包含纯红背景，能检出移位及“红色等于边缘”的错误。
- 将 A9 的存储与快照源码从 Git 标签读出，用完全相同的增强测试运行 A9 / A10；结果、发布帧数、处理周期和外部三拍延迟一致。
- 简化 RAM 字级模型与供应商模型在四个 40×80 场景的输出、周期、访问和写入计数一致。
- 640×480 两场景共 614,400 个打包单元检查 PASS，覆盖全部 120 块标签 RAM 的读回。采用生产控制器 / 引擎与经过上述对照的简化 RAM 原语模型；与 A9 的周期、访问和写入计数一致。

| 640×480 场景 | 保留像素 | 周期 | 存储访问 | 写入 |
| --- | ---: | ---: | ---: | ---: |
| 全弱、无强种子 | 0 | 1,536,000 | 307,200 | 0 |
| 一个强种子、全网格弱像素连通 | 307,200 | 16,561,936 | 3,372,484 | 307,200 |

仍为 O(P)，状态为 4P 位加固定寄存器，访问次数 ≤ `P+10V`、计算周期 ≤ `5P+49V+2`。按 148.5 MHz 折算约 10.34 / 111.53 ms，尚未板上计时；不包括冻结等待、捕获及发布。

## 构建与时序

使用 Efinity 2025.1.110 / Ti60F225I3，map、interface、pnr、pgm 四阶段均 PASS，新 bit / hex 已生成。

| 指标 | A9 | A10 | 变化 |
| --- | ---: | ---: | ---: |
| LUT4 | 14,531 | 14,810 | +279，约 +1.92% |
| FF | 9,717 | 9,802 | +85，约 +0.87% |
| RAM10 / DPRAM10 | 250 / 4 | 250 / 4 | 仍为 254 / 256 |
| DSP24 / DSP48 | 12 / 4 | 12 / 4 | 不变 |
| 148.5 MHz 像素域 setup 裕量 | +0.556 ns | +0.916 ns | +0.360 ns |
| 像素域 hold 裕量 | +0.026 ns | +0.026 ns | 不变 |
| 像素域分析最高频率 | 161.865 MHz | 171.880 MHz | +10.015 MHz，约 +6.19% |
| 全设计最小 setup 裕量 | +0.296 ns | +0.242 ns | −0.054 ns，仍通过 |
| 全设计最小 hold 裕量 | +0.026 ns | +0.026 ns | 不变 |

18 组 setup 与 18 组 hold 均为正裕量。像素域最长路径转为 RAM 读出 → 完整连接引擎 `mem_rdata[1]`，11 级逻辑、数据延迟 4.328 ns。A10 用少量逻辑与寄存器增加换取像素域裕量；全设计最小 setup 并未改善，仍由 DDR 相关路径限制。实际像素时钟保持 148.5 MHz，没有把分析最高频率当成板上的工作频率或帧率提升。

## 验证范围

完整连接仍仅用于冻结后的右侧 640×480 ROI，连续视频仍为局部近似。HDMI 未连接，本轮不下载到板子。当前板子保持原厂 3.5 寸彩色 Demo 对照配置，显示无摄像头画面的原因尚未定位。用户暂时没空观察屏幕，MIPI 显示、白平衡效果、HDMI 画面、DDR 无撕裂、实测周期和演示录像继续保留待验证。
