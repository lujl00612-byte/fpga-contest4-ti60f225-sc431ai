## 额外需求：3.5 寸屏彩色与白平衡

WB01 已生成下载文件并通过 JTAG 配置；4,423 项白平衡仿真检查通过。WB02 根据匹配的供应商 Ti60F225 DSI 示例补齐时钟通道多周期约束，DSI setup +2.437 ns，14 组 setup / 14 组 hold 全部通过，新位流与报告已保存。WB02 后续下载成功，但用户报告没有摄像头画面；原厂 3.5 寸 Demo 重新配置及冷启动对照也无画面。当前板上为原厂对照版本，显示故障正在排查；画面、彩条、白平衡效果及 D-PHY 启停过程尚未通过现场验收。

A12 期间完成离线 GPIO 对照，当前 MIPI 工程与提供的 V4 Key Demo 有三处输入 / 输出方向冲突；实际 PCB 版本与引脚电平尚未确认。已准备独立 RGB888 彩条的同步 / 打包诊断方案，当前白平衡彩条仍依赖输入视频同步。方案见 `docs/hardware/mipi-diagnostic-plan.md`，该诊断版位流尚未生成。
