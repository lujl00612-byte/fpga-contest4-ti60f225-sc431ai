# 赛题 4 要求与验收状态

依据本地《2026 FPGA竞赛赛题指南 -8.22(更正版)》第 25–26 页，以及易灵思选题指南第 13–15 页。状态中的“有 RTL”不等于现场验收通过。

## 基础要求

| 要求 | 当前实现 / 缺口 | 现场验收 |
| --- | --- | --- |
| 摄像头 ≥640×480，FIFO/BRAM 缓冲，不错行、不丢帧 | 原厂 SC431AI CSI 接收、DDR 缓冲及行存储；用户此前看到摄像头画面 | 长时间连续画面与帧计数仍待验证 |
| RGB 转灰度，DSP 或移位加法，无像素除法 | 77R+150G+29B 再右移 8 位 | 待 HDMI 对照原场景 |
| 3×3 Sobel，幅值为 |Gx|+|Gy|，两行缓冲，可调阈值 | V1–V3 已保存；当前 A6 进阶通路使用另一种幅值近似，需统一到 L1 并提供基础模式 | 待验证阈值边缘变化 |
| HDMI ≥640×480@60，原始灰度与二值边缘分屏或叠加，不撕裂 | 1080p HDMI 通路有 RTL 和构建报告；当前用户仅连接 MIPI，进阶通路灰度经过滤波，需提供基础对照模式 | **未连接 HDMI，尚未验收** |
| RTL、约束、实机演示视频 | 源码、约束和构建报告已入 Git | **演示录像未录制** |

## 进阶要求

| 要求 | 当前实现 / 缺口 | 验证状态 |
| --- | --- | --- |
| 3×3 中值，9 像素排序网络 | A6 行排序、三候选合并、流水寄存 | 待独立黄金参考回归 |
| 按键消抖调整阈值 | 按键阈值控制 | 待消抖和边界仿真 / 实测 |
| DDR 全帧缓存，冻结 / 回放 / 对照 | 原厂 DDR 帧缓存和冻结门控；A6 会在帧中间停写，需改成帧边界生效 | 待半帧冻结回归与实测 |
| 完整 Canny：Gaussian、方向、NMS、双阈值、滞后连接 | 前四部分有 RTL；A6 只保留紧邻强边缘的一层弱边缘，**不等于完整滞后连接** | 正在补齐任意长度连接算法 |
| 红色边缘叠加原始 RGB | 右侧红色边缘叠加已实现 | 待 HDMI 实测 |
| 简单圆形 / 矩形识别并显示结果 | A6 使用边界框角点启发式并画框；需改进识别特征和增加明确文字标签 | 待标准图案回归与实测 |
