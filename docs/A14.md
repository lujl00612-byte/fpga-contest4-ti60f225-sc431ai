# A14：缓存命中两周期响应

## 改动与接口

A13 的全连通 640×480 场景有 2,396,508 次缓存命中，占 3,372,484 次请求约 71%。A14 让命中请求在接受边沿生成旧单元数据、准备修改后的完整字并置位 ready，请求方在下一个 ACK 边沿消费响应。命中从 3 周期降为 2 周期，未命中保持 4 周期。

主字 / 移出字命中都使用各自的原始缓存字；交换时将旧主字保存在移出项。写入仍在消费 ready 的 ACK 边沿提交到 RAM，在此之前复位会丢弃预备写入并使两字缓存失效。捕获和视频读出仍使缓存失效。

未命中的 RESPOND 直接使用 RAM 读出，不再串接缓存选择。保留 A13 的每组 8 块 RAM 选择；RAM 视频读出仍为两拍，外部 RGB、DE、HS、VS 与独立边缘标记仍为三拍。未增加 RAM、缓存项数或帧状态容量。

## 周期与复杂度

完整 ROI 的独立 BFS 对照、全部打包单元与请求监控通过：

| 场景 | A13 周期 | A14 周期 | 减少 | 148.5 MHz 折算处理时间 |
| --- | ---: | ---: | ---: | ---: |
| 全弱、无强种子 | 1,290,240 | 1,044,480 | 245,760，19.05% | 8.69 → 7.03 ms |
| 全连通 | 14,165,428 | 11,768,920 | 2,396,508，16.92% | 95.39 → 79.25 ms |

两个场景的请求数、写入数、命中数、RAM 读出数和保留像素数与 A13 完全一致。减少的周期恰好等于命中数，每次命中省一拍。四个 40×80 场景也满足同一关系；供应商 RAM 与快速模型的输出和计数一致。

时间复杂度仍为 O(P)，状态仍为 4P 位加固定缓存 / 控制寄存器。请求上界 `P+10V` 保持不变；周期上界从 `5P+49V+2-H` 改为 `5P+49V+2-2H`。P 为 ROI 像素数、V 为保留像素数、H 为缓存命中请求数。

时间表来自仿真周期按固定时钟换算，未包含冻结等待、捕获和帧边界发布，尚未板上计时。全连通处理段约 79.25 ms，仍超出 60 Hz 的单帧时间；不能据此宣称连续视频完整 Canny 已完成。

## Efinity 实际构建与代价

使用 Efinity 2025.1.110 重新执行 map、interface、pnr、pgm，18 组 setup / 18 组 hold 均为正。

| 指标 | A13 | A14 | 变化 |
| --- | ---: | ---: | ---: |
| LUT4 | 14,244 | 14,287 | +43，约 +0.30% |
| FF | 9,746 | 9,737 | −9 |
| RAM10 / DPRAM10 | 250 / 4 | 250 / 4 | 总计 254/256 |
| DSP24 / DSP48 | 12 / 4 | 12 / 4 | 不变 |
| 像素域 setup 裕量 | +0.790 ns | +0.551 ns | −0.239 ns，仍通过 |
| 像素域 hold 裕量 | +0.026 ns | +0.028 ns | +0.002 ns |
| 像素域分析最高频率 | 168.237 MHz | 161.734 MHz | −6.503 MHz |
| 全设计最小 setup 裕量 | +0.252 ns | +0.256 ns | +0.004 ns |
| 全设计最小 hold 裕量 | +0.026 ns | +0.026 ns | 不变 |

实际像素时钟保持 148.5 MHz。本版缩短响应周期，同时降低像素域时序裕量。最长路径已从 RAM 数据读出转到 `engine/state[2] → memory/write_word_q[16]|CE`，19 级逻辑，报告 Delay 5.823 ns，Clock To Q + Data Path Delay 6.057 ns。A13 的最长路径为 RAM 读出到 `mem_rdata`，8 级、Delay 4.454 ns；两个版本的最长路径终点不同。后续优化应检查新请求译码和缓存写使能路径。

FF 为全设计综合计数，不能将 −9 个 FF 全部归因于源码删除的一个缓存选择寄存器。构建原始 warning、error、CDC 和布局报告均已保存。

## 独立验证和来源

- 常规回归 320,914 项检查通过，另有初始化延时 bit22 边界验证通过。检查总数比 A13 少 9,916，来自两个快照场景更早发布、仿真帧数减少；彩色输出检查仍为 13,440 项，参考和对齐预期未减少。
- 缓存专项 351 项通过，覆盖交换 / 淘汰 / 捕获 / 视频 / 复位，以及主字、移出字、未命中写入在 ACK 前中止。以 `HIT_CYCLES=3` 运行相同记分板和 A13 原始 RTL 也通过，命中 / 未命中次数相同。
- 17 块供应商 RAM 的 118 项请求数据 / 延迟、76,275 个视频单元检查通过；同一测试以旧三周期接口运行 A13 也通过。
- 全部 120 块供应商 RAM 的 736 项请求数据 / 延迟、571,115 个视频单元检查通过，包含每拍更换地址、跨组和视频间隙。
- 跨块快照通过 140,733 项同步、40,320 项彩色输出、140,733 项独立边缘标记检查，保持三拍对齐。
- 四个 40×80 场景使用供应商 RAM 和快速模型校准；640×480 两场景使用已校准快速模型，614,400 个单元与独立 BFS 对照通过。全尺寸 BFS 的 RAM 模型与全尺寸连续 RAM 流测试的供应商模型分别记录。
