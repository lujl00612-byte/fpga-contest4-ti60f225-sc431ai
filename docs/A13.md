# A13：分组 RAM 读出，缩短完整连接关键路径

## 改动与范围

A12 的最长像素路径是 `bank[28].ram → mem_rdata[1]`，经过 12 级逻辑。A13 将 120 块 RAM 的可变下标选择改为每组 8 块、共 15 组的两级选择。组内与组间选择信号在原来的 RAM 读入边沿寄存，数据经过平衡的 OR 树。

该改动保持原有接口：缓存命中 3 周期、未命中 4 周期，RAM 视频读出两拍，外部 RGB、DE、HS、VS 和独立边缘标记仍为三拍。两字缓存的交换、淘汰、ACK 写入、复位和捕获 / 视频失效规则沿用 A12。

选择寄存器从 7 位改为 8 位组内选择加 15 位组选择，源码增加 16 位选择状态；全设计综合 FF 增加 21 个，两者不能直接视为同一个数量。状态容量与 RAM 块数没有增加。

## 实际构建结果

使用本地 Efinity 2025.1.110，重新执行 map、interface、pnr、pgm 四阶段。18 组 setup 和 18 组 hold 全部为正；这是本次布局的结果，尚未经过板上计时或不同布局的统计。

| 指标 | A12 | A13 | 变化 |
| --- | ---: | ---: | ---: |
| LUT4 | 14,716 | 14,244 | −472，约 −3.21% |
| FF | 9,725 | 9,746 | +21，约 +0.22% |
| RAM10 / DPRAM10 | 250 / 4 | 250 / 4 | 总计仍为 254/256 |
| DSP24 / DSP48 | 12 / 4 | 12 / 4 | 不变 |
| 最长像素路径逻辑级数 | 12 | 8 | −4 级 |
| 报告路径 Delay | 4.708 ns | 4.454 ns | −0.254 ns |
| Clock To Q + Data Path Delay | 6.072 ns | 5.818 ns | −0.254 ns |
| 148.5 MHz 像素域 setup 裕量 | +0.536 ns | +0.790 ns | +0.254 ns |
| 像素域 hold 裕量 | +0.029 ns | +0.026 ns | −0.003 ns，仍通过 |
| 像素域分析最高频率 | 161.342 MHz | 168.237 MHz | +6.895 MHz |
| 全设计最小 setup 裕量 | +0.246 ns | +0.252 ns | +0.006 ns |
| 全设计最小 hold 裕量 | +0.026 ns | +0.026 ns | 不变 |

A13 的最长像素路径起点变为 `bank[60].ram`，终点仍为 `mem_rdata[1]`。实际像素时钟保持 148.5 MHz，报告分析频率的增加不能当作实际帧率或处理速度提高。

## 周期与复杂度

640×480 的独立 BFS 对照通过，所有计数与 A12 保存的同场景结果一致：

| 场景 | 保留像素 | 处理周期 | 请求数 | 缓存命中 | RAM 读出 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全弱、无强种子 | 0 | 1,290,240 | 307,200 | 245,760 | 61,440 |
| 全连通 | 307,200 | 14,165,428 | 3,372,484 | 2,396,508 | 975,976 |

按 148.5 MHz 折算约为 8.69 / 95.39 ms，未包含冻结等待、捕获与帧边界发布，尚未板上计时。A13 优化组合路径和 LUT 用量，没有降低这两场景的周期数。

完整连接时间复杂度仍为 O(P)，状态仍为 4P 位加固定大小的缓存 / 控制寄存器，请求数上界仍为 `P+10V`，周期上界仍为 `5P+49V+2-H`。P 为 ROI 像素数，V 为保留像素数，H 为缓存命中请求数。固定硬件规模的分组选择不会改变算法的渐近复杂度。
