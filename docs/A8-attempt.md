# A8 构建尝试：算法通过，RAM 映射失败

2026-09-30。完整 8 邻域滞后连接 DFS 与独立 BFS 参考逐像素一致：24 个 32×24 帧，共 18,432 个像素，覆盖全弱、全强、长链、闭环、对角线、随机噪声和可变存储延迟。

冻结快照接入仿真也通过：52,059 项时序检查、13,440 项输出颜色检查，包含存储打包、整帧发布和重新捕获。

硬件综合未通过发布条件。`canny_tag_memory` 原写法包含独立的两路读和不同地址的两路写；Efinity 报告 `write and read address port is not compatible for dual-ported ram`，把大量存储拆入逻辑。主动终止了本次综合，**没有 A8 下载文件，也未下载该版**。

下一步：冻结分析和结果显示互斥，复用一个读端口；捕获和引擎写也复用同一个写端口，匹配 RAM10 的一读一写结构。修正后重新仿真和构建为 A8R1，不覆盖这次失败记录。

## 另外发现的板卡资料冲突

本地相机 Demo 的 `led[0..3]` GPIO 与 V4 Key Demo / V4 原理图的按键、UART、LED 映射不一致。例如相机 Demo 把 GPIOR_21/22 作为 LED，Key Demo 把它们作为 KEY2/KEY1；GPIOR_27 在相机 Demo 中为复位输入，而在 Key Demo 中为 LED0。

目前保持此前用户确认能显示画面的 3.5 寸原厂相机连接配置。HDMI 版本仅构建，尚未下载；后续正式 HDMI 上板之前，须依据实际 PCB 丝印版本核对这些 GPIO，不能把“构建成功”当成板卡版本匹配的证据。
